# 🚀 LangChain Complete Basics

This repository contains beginner-friendly examples of the most important LangChain concepts. Each example is simple, well-commented, and easy to understand.

## 📚 Topics Covered

- Basic LangChain Chatbot
- AI, Human & System Messages
- PromptTemplate
- ChatPromptTemplate
- FewShotPromptTemplate
- MessagesPlaceholder
- StrOutputParser
- RunnableLambda
- RunnableBranch
- RunnableMap
- RunnableSequence
- RunnableParallel
- RunnablePassthrough
- Tools
- Agents
- Memory

## ⚙️ Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file and add:

```text
OPENAI_API_KEY=your_openai_api_key
```

Run any example:

```bash
python runnable_lambda.py
```

This repository is intended for learning LangChain fundamentals and preparing for AI/LLM interviews.
